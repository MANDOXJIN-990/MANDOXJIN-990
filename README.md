## `whoami`

I'm an Electronics and Computer Engineering student passionate about building reliable, efficient systems at the intersection of hardware and software.

My interests span embedded firmware, low-level software architecture, digital systems, and semiconductor design. I enjoy understanding how systems work beneath the abstraction layer—from MCU peripherals and communication protocols to processor architectures and silicon implementation.

- 🔭 **Currently exploring:** Embedded firmware, RTOS, CAN communication, and hardware-software integration.
- ⚙️ **Engineering philosophy:** Modular architecture, predictable behavior, efficient resource utilization, and maintainable code.
- 🧠 **Long-term direction:** Embedded systems, computer architecture, FPGA, ASIC, and VLSI design.
- 🛠️ **Building:** Firmware projects, communication tools, and practical electronics prototypes.

## `featured_projects`

### 🚗 Wireless CAN Bus Analyzer

An ESP32-based CAN monitoring project that simulates vehicle communication and streams CAN frames to an IoT dashboard.

- Generates and analyzes CAN frames.
- Publishes data over MQTT.
- Visualizes live vehicle communication using Node-RED.
- Built with PlatformIO, ESP32, MQTT, and Wokwi.

### ⚙️ IoT-Based DC Motor Health Monitoring

A real-time motor monitoring system using sensor data and an IoT dashboard.

- Measures temperature, vibration, and rotational speed.
- Uses ESP32, DS18B20, MPU6050, and Hall-effect sensing.
- Displays measurements locally and remotely.
- Supports threshold-based health alerts.

### 🔐 Secure Enterprise Network

A simulated enterprise network designed with secure communication and structured network architecture.

- Multi-router topology and subnetting.
- Network segmentation and access control.
- Implemented and tested in Cisco Packet Tracer.
